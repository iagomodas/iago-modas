# Registro de migração — marca e coleção

> **Registro histórico:** este documento registra a migração de 17/08/2026, anterior ao rebranding para IAGO MODAS. O valor de marca anterior é mantido apenas para documentar o dado gravado naquela data.

Em **17 de agosto de 2026**, foi aplicada com sucesso no projeto Supabase `nqigoxncebescsdpeyjc` a migração `202608170005_product_brand_collection.sql`.

A atualização acrescenta os campos `brand` e `collection` à tabela `public.products`. Os produtos que já existiam receberam o valor inicial **OVERSIZED MODAS** como marca, sem alterar nome, categoria, preço, estoque, fotos, clientes ou pedidos.

O painel administrativo permite alterar esses dados ao cadastrar ou editar qualquer categoria de produto, incluindo camisetas, calças, bermudas, calçados, acessórios, perfumes e kits.
